---

## 🌍 Non-Technical Contributions (Open to everyone)

You don't need coding skills to improve the application! Here's how you can help:

### 📝 Translations
The application already supports several languages, but we want to go further:
- **Improve existing ones**: If you see a typo or an awkward phrase.
- **Add a language**: Do you speak a language not listed? Propose it to us!
- **How to do it?**: Open an [Issue](https://github.com/orionmoon/sadaa/issues) or start a [Discussion](https://github.com/orionmoon/sadaa/discussions) with your proposal.

### 💡 Content Suggestions
- Propose new **Types** (e.g., Well-being, Social relations).
- Suggest relevant **Categories** (e.g., "Patience in trials").
- **How to do it?**: Use the **Discussions** tab to share your thematic ideas.

### 🐛 User Feedback
- Report a bug or a display issue.
- Propose an idea to make the interface simpler or more beautiful.

---

## ✨ New Feature Suggestions

Have an idea to make Sadaa even more useful or pleasant to use? We love new ideas!

- **UI Improvements**: To make navigation smoother.
- **New Sharing Options**: To spread wisdom more easily.
- **Contemplation Tools**: Any feature that encourages reflection and peace.
- **How to do it?**: Use the **[Discussions](https://github.com/orionmoon/sadaa/discussions)** tab to propose and debate your ideas with us, or open a **[Issue](https://github.com/orionmoon/sadaa/issues)** of type "Feature Suggestion".

---

## 📜 Code of Conduct

This project is built on kindness and respect. We expect all contributors to be courteous and open-minded.
